# DP-800 Lab 02 — Objetos de programación con T-SQL

Laboratorio de preparación para **Microsoft DP-800: Developing AI-Enabled Database Solutions**. Se trabaja con **AdventureWorksLT** para crear y probar una vista, un procedimiento almacenado, funciones escalares y de tabla, y un trigger de auditoría.

## Requisitos

- SQL Server 2019 o superior
- SQL Server Management Studio (SSMS)
- Base de datos `AdventureWorksLT`
- Conocimientos básicos de T-SQL
